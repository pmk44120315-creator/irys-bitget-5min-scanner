## 실제 수정·실행 범위
이번 작업은 기존 V39 중단 지점에서 재개했다. Cloudflare V35.1 실전 진입방향 모델은 변경하지 않았다. 새 학습 모델의 실전 정확도 개선을 입증했다고 주장하지 않는다.

### 1. 중단 오류 수정 및 실제 저장 확인
기존 V39 실행 42368638423은 최초 장부에 research_only 등 새 안전 메타데이터가 없어서 검증 단계가 실패했다. normalizeLedger로 기존 기록을 보존한 채 메타데이터만 정규화했다. 유효하지 않은 기존 장부 스키마는 거부한다.

저장 작업은 별도 git worktree에서 읽기 시점의 data/irys-v39-ack-feedback SHA를 기준으로 처리하고, main이나 Worker에 쓰지 않는다. non-force push 후 원격 장부를 다시 읽어 바이트 일치를 확인한다. 새 실행 42374854350에서 테스트·실제 저장·재조회 모두 성공했다. 실제 AKEUSDT SHORT 발송 증거와 5/15/30/60분 가격 결과 1건이 별도 데이터 브랜치에 저장됐다. 이는 모든 과거 Telegram 알림을 완전 수집했다는 뜻은 아니다.

### 2. 실제 학습 모델 구현
단순한 상태점검이나 고정 조건 추가가 아니라, 당시 입력과 이후 결과로 로지스틱 회귀 및 얕은 랜덤포리스트를 실제 학습했다. 후보 설정을 사전에 고정하고 검증 구간의 balanced accuracy로 모델을 선택했다. 최종 시간 구간으로 설정을 재조정하지 않았다. 학습에 쓰지 않은 종목도 별도로 평가했다.

- 원본 V30 패킷 복원: 시각 검증을 통과한 V36 기록 1,939건 중 1,933건을 판단 이전에 커밋된 원본과 연결. 6건은 미복원으로 남김.
- 여러 시간대 가격·시장·OI·체결 정보를 포함한 기존 V22 기록의 실측 후속 bid/ask를 이용한 별도 학습.
- 최근 5,000건 한도를 넘어 원본 GitHub 커밋을 거슬러 2026-11-01~11-07의 51,688개 고유 이벤트 복원. 동결된 입력 충돌 0, 실측 결과 충돌 0. 최초 기록까지 조회 완료; 수집 오류 0.
- 원래 가격 방향과 스프레드/수수료 영향을 구분. 원본 mid→후속 실제 mid 방향, ask→bid/반대 방향 호가 변화, 0.20% 추가 비용 가정은 서로 다른 지표로 표시.
- 시간순 train/validation/test, 60분 분리, 20% 종목 보류, 미래 가격이 학습 입력에 섞이지 않는 검사 적용.
- 직렬화한 모델을 다시 학습하거나 가중치를 바꾸지 않고 이후 기간에 재검증했다.

## 남은 핵심 문제와 재개 지점
1. 실전 V35.1 방향 판단 교체는 미완료이며 이번 후보들은 그대로 교체하면 안 된다.
2. 후속 실제 호가 미측정 비율이 높다. 데이터 연결 성공과 학습 가능한 입력-결과 짝 확보는 다르다.
3. V22 코드상 정확한 목표 시각 이전 호가는 라벨로 쓰지 않고 다음 회차는 허용 창을 넘으면 미측정이 된다. 실제 미측정 표본에서 목표 직전 호가가 존재하는 사례도 발견됐다. 목표 시각의 후속 호가를 별도로 회수하는 방식을 다음 검증 대상으로 삼되, 목표 이전 호가를 미래 결과로 둔갑시키지 말 것. 해당 런타임 수집 변경은 이번에 적용하지 않았다.
4. 가격/호가/체결이 드문 구간을 전체 수급으로 가정하지 말 것. 고정한 소표본 조건을 늘리거나 무조건 반대 방향으로 뒤집는 방식은 성능 증거가 아니다.
5. 지금까지의 실패 실험도 보존한다. 다음 작업은 이 소스·데이터·결과를 재사용하고 처음부터 같은 실험을 반복하지 않는다.
