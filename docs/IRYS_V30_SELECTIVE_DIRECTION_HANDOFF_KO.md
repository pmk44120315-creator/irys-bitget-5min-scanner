# IRYS V30 — 실제 자료 재검사 후 종목별 방향 알림

최종 검증 기준: **2026-11-04 03:32:50 KST**. 현재 운영 버전 `IRYS-V30-SELECTIVE-PAIRED-DIRECTION-20261104`.

## 현재 상태
기존 V29의 무조건적인 시장 Telegram 발송 차단을 대체했다. 일반 WATCH/옛 발송 경로는 계속 차단하고, 새로운 V30 경로에서 원본 자료를 다시 검증한 개별 종목만 일회성 발송 허가를 받을 수 있다. 현재 자료가 맞는다는 판단은 미래 방향 적중률이나 수익성이 입증됐다는 뜻이 아니다. 적중률을 보장하거나 보정된 확률을 표시하지 않는다.

기존 Cloudflare 5분 Cron, AI/KV/Telegram/GitHub 바인딩, 기존 시장수집기, 별도 GPT 감시 작업은 유지했다. 계좌/주문 API와 비공개 장부 추출 엔드포인트는 추가하지 않았다. 테스트 Telegram 메시지나 수동 시장 실행을 보내지 않았다.

## 확인된 원인과 변경
1. V29의 공통 telegram 함수는 검사 결과와 무관하게 예외를 발생시켰다. V30은 실제 근거가 맞는 사례는 전송할 수 있고, 오래된/누락/반대반응/위조된 ready표시는 전송할 수 없도록 단일 사용 허가를 도입했다.
2. Cloudflare의 직접 Bitget 자료 접근 문제가 정밀검사에서도 반복됐다. 정상 접근이 확인된 GitHub 실행기에서 공식 V2/V3 신원/위험자료, 실제 체결·호가 첫 관측, 이후 신규체결·호가 두 번째 관측, 마지막 최신 호가를 수집한다. Worker는 고정된 인증 GitHub 파일 경로를 읽고 원본 자료를 다시 검사한다.
3. 기존 한 회차 6개 검사 상한 대신, 별도 후보 목록의 모든 종목을 검사한다. 현물 후보 최대12개, 선물 LONG최대12개/SHORT최대12개를 현재 움직임에서 선정한다. 전체 상장종목 모두를 정밀검사한다는 뜻은 아니다. 6은 새 실행기의 동시 요청 수이며 총 검사 수가 아니다.
4. 선물 상승만 보지 않고 하락 후보도 SHORT로 검사한다. 현물은 BUY만 허용한다. 기존 종목/경보 정합성과 두 번의 실제 새로운 체결 근거 조건을 없애지 않았다.
5. 마지막 호가가 두 번째 관측보다 역행하거나, 가격 구조가 깨졌거나, 체결이 겹치거나, 시간이 오래됐으면 거절한다. 관측 분리는 통계적으로 독립된 수익 표본을 입증한다는 뜻이 아니다.

## 전송과 기록
- 최대 1종목/회차, 기존 시장알림 2회/시간과 동일종목90분 재알림 제한 유지.
- 현재 근거가 확인된 BUY/LONG/SHORT, 근거시각, 매수·매도호가, 근거 이탈 참고선, 짧은 유효시각을 보낸다. 확정수익이나 미래확률을 표기하지 않는다.
- 전송 전 별도 예약키를 저장한다. Telegram 응답이 불확실하면 무작정 재전송하지 않는다.
- KV의 동일키 초당1회 쓰기 제약을 재현해 예약키와 ACK키를 분리했다. 실제 양의 message_id를 받은 경우만 발송1건으로 기록한다. 기기 수신은 별도로 미확인이다.
- KV는 최종 일관성 저장소이므로 임의로 겹친 외부 실행까지 포함한 트랜잭션형 exactly-once를 보장한다고 주장하지 않는다.
- 실제 ACK 기록과 단순 후보 가설을 분리한다. 후보 탈락 여부도 당시 근거와 함께 보존하며, 실제 발송은 비공개 상태에 별도 기록한다.
- 이후5/15/30/60분의 실제 공개 호가가 목표시각 범위 안에서 확보될 때만 결과를 계산한다. 없는 목표호가는 미측정이다. 추가0.20%는 비용 가정이며 실제 계좌 손익이 아니다. 자동으로 미래 적중률이 보증되거나 매매가 실행되지는 않는다.
