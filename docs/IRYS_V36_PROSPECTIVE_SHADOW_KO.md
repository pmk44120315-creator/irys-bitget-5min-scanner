# IRYS V36 — 반증형 수급 가설·미래경로 실증 엔진 (2026-11-06)

## 목표
사용자 최우선 목표는 빗썸 급등 전 포착과 비트겟 LONG/SHORT 미래 방향 정확도 향상이다. 과거 V35.1 발송승인 기록의 5분 방향 일치가 33건 중10건이었고, 짧은 체결·호가 일치만으로 미래 방향을 보장할 수 없음을 확인했다. 100% 적중은 보장 불가. 알림 0건으로만 오답을 없애는 것도 목적이 아니다.

## 배포 범위와 경계
V36은 기존 V35.1 Worker를 임의 수정하지 않는 **독립 운영 데이터 수집·평가 경로**이다. 정규 V30 공개자료 생산 workflow가 성공적으로 종료되면 별도 V36 job이 실행되며, GitHub에 두 개의 V36 공개 시장자료만 기록한다. 텔레그램·계좌 API·개인정보·주문과 연결되지 않는다. 기존 V35.1의 방향 검사, 급락 위험경보, 바인딩, 5분 수집, 발송 제한을 모두 유지한다.

- `deployment/v36_hypotheses.mjs`: BUY/LONG/SHORT의 기존 방향 증거를 지지하는 관찰과, 실패를 시사하는 역방향 체결·호가·상대시장 관찰을 분리해 기록. 점수는 **확률 아님**. 일부 체결 표본은 전체 CVD나 세력 의도를 증명하지 않는다.
- `deployment/v36_paths.mjs`: 출발 전 확보한 실제 체결 범위와 스프레드에서 목표/무효화 가격을 동결한 뒤, 미래 공식 1분봉으로 어느 쪽에 먼저 도달했는지 측정. 같은 1분봉에 양쪽 동시 터치 시 `AMBIGUOUS_BOTH`, 분봉 누락 시 `UNMEASURED_GAP`. 미측정은 성공으로 세지 않음. 실제 체결·수익 아님.
- `deployment/v36_shadow.mjs`: 같은 종목·방향·30분 단위로 중복 가설을 제거하고 원본 판단 시점을 고정. 후속 5/15/30/60분 결과 별도 수집. 미래 자료는 최초 판단에 사용하지 않음.
- `deployment/v36_runner.mjs`: 기존 V30 공개자료와 공식 거래소 분봉 읽기 전용. Bithumb·Bitget 공급 장애는 명시적 `source_errors`로 남김. 40종목/회차 우선 비교, 원본 시장 정보는 변경하지 않음.
- `.github/workflows/v36-public-shadow.yml`: 정규 V30 성공 종료 뒤 작업을 실행, 새 공개 데이터 `data/v36_shadow_latest.json`과 `data/v36_shadow_state.json`만 갱신. 중복 실행 방지, 실패 시 강제푸시/기존 자료 덮어쓰기 없음.

## 배포 승인 근거
`v36-review.yml` 원격 실행의 전체 Python178/Node277 검사 통과. 최초 실자료 시험은 V30 자료 갱신 전이어서 `SOURCE_NOT_ELIGIBLE`, 실제 등록0건이었다. 이는 실패를 성공으로 바꾸지 않으며 정규 연동 후의 자연 실행·새 후보 등록은 별도로 확인한다.

## 성능 평가와 운영 전환 방침
V36은 **정확도 향상 미입증**이므로 기존 실거래 방향 알림의 기준을 자동 교체하지 않는다. 실제 발생 후 미래자료로만 시험하고, 거래소·방향·종목별 최소 표본, 미측정 비율, 단순기준과 같은 기회/발송예산을 적용한 시간순 독립 평가를 비교한다. `v36Gate`는 우수 성적이 쌓이더라도 **자동 승격을 하지 않는다.** 그 이후 별도 소스 수정·회귀검증·롤백 가능한 Worker 배포가 필요하다.

정상 작동, 테스트 통과, 실제 방향 적중률은 서로 다른 상태다. 원본 감시기와 자료를 삭제하거나 이전 검증 결과를 덮어쓰지 않는다.
