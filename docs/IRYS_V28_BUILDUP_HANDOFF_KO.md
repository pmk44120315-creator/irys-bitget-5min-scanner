## 2. 탐색 개선
기존 빗썸 탐색은 직전 구간0.70% 상승에 집중해 작은 상승이 누적되는 경로를 놓칠 수 있었다. 당일 상위 변동률은 이미 발생한 상승이지 미래급등 보장이 아니다. 일부 사진 종목은 과거 실제 발송도 있었으므로 전부 미탐이라고 단정하지 않고 수집/관찰/선정/차단/발송을 구분한다.

V28.1은 공식 원화종목 전체를 관찰하면서 다음을 분리한다.
- 실제 관측 구간의 시장 중간값 대비 가격 강도와 기준가격에서 누적된 상대적 상승.
- 동일 비교종목 집합의 거래대금 점유율 변화. 거래대금은 순매수가 아니며 비교집합이 바뀌면 해당 변화는 미확인 처리.
- 상승 형성/확장/재가속/약화/형성 기준 이탈. 포착 뒤 상태도 보존.
- 위험 경보·유의종목은 관찰표에서 사라지지 않지만 위험을 표시하고 정상 매수후보로 승격하지 않음.
- 최근체결이 오래됐거나 비교구간이 부족하면 미확인/기준수집 단계로 표시. 전체 관찰대상 수와 현재 신선한 비교표본 수를 구분.

36개 이력 보존은 저장 한도이지36봉 연속 확인 조건이 아니다. 후보 점수는 보정된 확률이 아니다. 알림상한 전에 탐색장부를 갱신하므로 발송제한이 탐색중단으로 이어지지 않는다.

기존 시간당2개 시장-WATCH 메시지 상한을 늘리지 않고 최대3종목을 한 메시지에 묶는다. 한 ACK는 한 발송이며, 각 종목의 실제 호가·근거·중복방지·후속평가 사건은 따로 저장한다. 경보종목 참고문구와 실제 후보는 구분한다. 새 묶음 영수증은 v28_alert_events.py로 종목별 확장할 수 있으며, 영구적인 새 사후평가 스케줄을 추가했다고 주장하지 않는다.
