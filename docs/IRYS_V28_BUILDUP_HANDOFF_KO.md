# IRYS V28 — 급등 형성 탐색·전체 관찰·실제 알림 사후 검증

## 작업 연속성
2026-11-02 중단된 V28 작업은 공식 시장자료·영수증 감사까지만 저장돼 있었다. 기존 V27.2 운영 소스 SHA256 f9213445d95a1c52e4d72eb47961e8d63188d3d99ed7876894d69907b3e00b1f를 확인하고, 기존 감시기·시장자료·예약주기를 유지한 채 별도 브랜치에서 구현했다.

## 확인한 문제와 범위
기존 Bithumb 탐색은 직전 관측 구간 0.70% 상승에 집중해 작은 상승이 누적되는 경로를 놓칠 수 있었다. 시장 상위 변동률 자체는 이미 발생한 움직임이며 미래 급등을 증명하지 않는다. 일부 상위 종목은 과거 실제 발송된 기록도 있었다. 따라서 전부 미탐이라고 단정하지 않고 수집/관찰/후보선정/안전차단/발송상한을 구분한다.

새 V28에서는 한 글자 심볼이 잘못 제외되는 결함도 실제 공식 목록과 대조하여 발견·재현·수정했다. 원래 V27에 이 결함이 있었다고 소급 주장하지 않는다.

## 실제 변경
- 공식 KRW 종목 모두를 관찰 장부에 보존. 경보/유의종목도 위험 표기와 현재단계를 유지하지만 매수 후보로 승격하지 않음.
- 직전 0.70% 상승 여부 대신 비교 가능한 실제 관측 구간의 시장 중간값 대비 움직임, 실제 기준가격에서 누적된 상대 강도, 거래대금 점유율 변화를 서로 다른 후보 경로로 사용.
- 거래대금은 순매수가 아니다. 비교 종목 집합이 바뀌면 점유율 변화를 미확인 처리. 잘못된 한 종목 값이 전체 분모를 오염시키지 않음.
- 같은 시점 중복 실행, 누적거래대금 리셋, 실제 체결시각 오류, 비교간격 누락은 가짜 가격/거래량으로 채우지 않음. 36개 기록 보존은 저장 한도이지 36봉 연속 확인 조건이 아님.
- 첫 발견 이후 상승 형성/확장/재가속/약화/기준 이탈을 추적. 당일 상위 종목은 별도 참고 목록으로 유지.
- 관찰 장부는 발송 상한 전에 갱신하므로 알림이 막혀도 탐색 상태가 사라지지 않음.
- 기존 시간당2건 시장-WATCH 상한을 유지하면서 최대3종목을 한 메시지로 묶음. 한 ACK는 한 발송이고, 포함된 각 종목은 별도 증거/중복방지/사후평가 대상으로 기록.
- 기존 선물·현물 확정 증거 함수, 공식 위험검사, 현재 호가 검사, Bitget 최신 인증 공급 경로, Cloudflare Cron과 바인딩 보존. 자동주문·계좌접속·인위적 테스트 메시지 없음.

## 구현 파일
- deployment/v28_discovery.mjs: v28Discover, v28ChooseBundle, v28Brief.
- deployment/v28_messages.mjs: 다종목 관찰 메시지와 개별 증거 스냅샷.
- deployment/build_v28_worker.py: 정확한 V27.2 원본에서 검증된 V28 생성.
- v28_alert_events.py: 기존 단일 종목과 새 묶음 영수증을 종목별 실제 ACK 사건으로 확장. WATCH를 LONG으로 바꾸지 않음.
- deployment/release_v28_guarded.mjs: 정확한 원본 해시 확인, 설정 보존, 실패 시 원복.

## 검증 근거
- 실제 최근 알림 재감사: 실행41446205533. 과거가격은 첫 완성 post-ACK 분봉 시가 기준이며 실제 체결 손익이 아님. 누락 목표봉/기준봉은 미측정.
- 원격 전체 회귀 및 실제487종목 대조: 실행41449601682 성공. Python178 + Node101 통과.
- 추가 배포 보호 테스트4개: 원본변경 시 쓰기금지, 설정변경 시 원복, 정상배포, 기존서버 이상 시 중단.
- V28 빌드 SHA256: e3fa2f1da6151ceb419fe5f21bf5fae8afd3db5a2d8068425f0986e64692c19d.
- 보호배포 및 자연예약 확인 실행:41450016477. 실제 최종 상태는 해당 실행의 deployment.json/natural_proof.json으로 판단한다. 문서 작성 시점에는 자연 실행 검증이 진행 중이었다.

## 주장하지 않는 사항
테스트 통과, 과거 전체종목 조회, 후보가 더 많이 남는 사실은 미래 급등 적중률·수익성 향상을 증명하지 않는다. 새 점수는 확률이 아니며 관찰 메시지는 매수/롱 지시가 아니다. 이미 오른 종목을 뒤늦게 포착한 것과 급등 전에 포착한 것은 사전 발행 시각과 이후 실제 경로로 별도 평가해야 한다.

## 재현
원본 V24 release 파일을 확보하고 build_v27_worker.py로 V27.2를 생성한 후, build_v28_worker.py에 그 정확한 파일을 넣는다. 전체검사 시 V27_BASE_WORKER와 V28_BASE_WORKER를 각 원본 경로로 지정한다. 저장된 시장데이터나 기존 프로덕션 파일을 정리한다는 명목으로 삭제하지 않는다.
