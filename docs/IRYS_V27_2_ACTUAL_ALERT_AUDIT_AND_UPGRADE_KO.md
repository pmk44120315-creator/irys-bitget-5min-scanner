# IRYS V27.2 실제 텔레그램 사후 감사 및 운영 업그레이드

## 실제 알림 감사
2026-11-02 수집 시점까지 KV에 저장된 실제 Telegram Bot API 수락 영수증 227개를 전체 페이지 조회했다. 사후 결과 통보 22개는 제외해 최초 시장 알림 205개를 감사했다. 91개는 message_id+symbol로 저장된 방향 자료를 연결했고, WATCH는 방향 예측 적중으로 세지 않았다. 기기 수신은 미확인이다.

과거 알림에는 정확한 발송 당시 가격/메시지 본문이 없었으므로 공식 거래소 1분봉 중 발송 시각 다음 완성 구간의 시가를 기준으로 5/15/30/60분 후 종가를 비교했다. 실제 매매/체결가/수수료·슬리피지 수익이 아니며 누락 구간은 임의 보간하지 않았다. 원본 JSON·CSV는 사용자용 로컬 검증 패키지에 보존한다. 공개 저장소에는 개인의 전체 알림 내역을 새로 게시하지 않는다.

기존 명시적 방향 91개 중 15분 평가 가능 82개는 방향 일치27/불일치44/보합11, 나머지9개 미측정이었다. 서로 다른 과거 버전의 자료이며 V27의 성적은 아니다. 검증 실행: 41374801709.

## 새 운영 기능
1. 최신 체결가 한 호가 왕복을 상승으로 오인하지 않도록 현재 최우선 매수·매도호가가 정확한 과거 기준 가격에서 실제 이동했는지 확인.
2. 샘플 체결을 동일 거래대금 전반/후반으로 나눠 압력과 가격 반응을 비교. 매수 우세에도 하락하면 매수 압력 실패, 매도 우세에도 상승하면 매도 압력 실패로 기술. 전체 CVD/지속 흡수/미래 반전 확정은 아니다.
3. Bithumb 실제 REST에서 서로 다른 체결행의 동일 sequential_id를 확인. 별개 관측 행은 보존하고 같은 밀리초는 묶어 순서를 발명하지 않으며 고유 체결수는 미확인 표시.
4. 기존 선물 방향 증거가 발송 직전 현재 호가에서 이미 반대로 무너졌는지 검사. 원본 증거와 종목 안전차단 유지.
5. 새 영수증에는 메시지 본문, 정확한 ACK시각, 기준가격, 현재 호가, 반응 근거를 비공개 KV에 저장. 공개 건강상태에는 민감한 본문/상세근거를 제외.
6. 기존 5분 Cron, AI/KV/Telegram/GitHub 연결, GPT 기존 감시기, 전체 발송 상한을 유지. 주문/API계좌/테스트 알림 추가 없음.

## V27.1 → V27.2 운영 실패 원인 및 수리
V27 및 V27.1에서 GitHub 원본 브랜치 URL의 이전 자료가 자연 Cron 중 반복 반환되는 실제 결함이 확인됐다. 12:00KST 자연 실행이 12:02:20까지 11:55:58 자료만 읽었다. 새 자료는 GitHub에 12:01:01 반영됐다. 45초 대기를90초로 늘리는 수정만으로 해결되었다고 판정하지 않았다.

실제 Cloudflare에서 기존 GITHUB_DISPATCH_TOKEN으로 GitHub Contents 인증 읽기 권한을 별도 확인한 후, V27.2는 이 경로를 우선 사용한다. 토큰은 api.github.com에만 전달하고 public raw fallback에는 전달하지 않는다. 원래90초 신선도/동일 수집회차/원본시각 연결 검증을 완화하지 않는다. 조회 오류 메시지가 토큰을 노출하지 않도록 제한된 상태코드만 저장한다.
