# IRYS V27.2 — 실제 Telegram 알림 사후 감사 및 운영 업그레이드

최종 확인: 2026-11-02 12:12 KST. 현재 실제 운영 버전은 `IRYS-V27.2-EXECUTABLE-RESPONSE-AUTHFRESH-20261102`.

## 1. 실제 발송 자료와 평가 범위
실제 Telegram Bot API 수락 영수증 227개를 KV 전체 페이지에서 확보했다. 사후 결과 통보22개를 제외한 최초 시장 알림205개를 공식 거래소1분봉으로 대조했다. 91개는 message_id와symbol이 모두 같은 저장 결과에서 원래 방향을 복원했고, WATCH는 매수/롱 적중으로 세지 않았다. 사용자의 기기 수신 여부는 미확인이다.

과거 영수증에는 정확한 메시지 본문과 발송 시점 가격이 없어서, 발송 시각 다음 완성1분봉의 시가를 기준으로5/15/30/60분 후 종가를 비교했다. 실제 체결가·수수료·슬리피지·레버리지 수익률이 아니다. 원본 또는 목표 분봉 누락은 보간하지 않았고, 내부 경로가 불완전하면 최대 상승/하락 폭도 확정하지 않았다. 원본 JSON과CSV는 사용자용 검증 패키지에 제공하며 공개 저장소에 전체 개인 알림내역을 추가 게시하지 않는다.

명시적 방향91개 중15분 평가 가능82개는 방향 일치27, 불일치44, 보합11이고9개는 미측정이다. 여러 과거 버전이 섞인 결과이며 V27.2의 적중률이 아니다. 감사 실행:41374801709.

## 2. 실제 반영한 기능
- **호가 이동 검증:** 최신 체결가의 한 호가 왕복과 현재 최우선 호가의 실제 이동을 구분한다. 원본 기준가격을 별도로 보존한다. 호가가 있다고 실제 물량·슬리피지까지 확보됐다고 간주하지 않는다.
- **거래대금 기준 압력-반응:** 관측 체결 금액을 전반/후반으로 나눠 매수·매도 압력이 가격 이동으로 이어졌는지 분리한다. 매수 우세에도 하락하면 매수 압력 실패, 매도 우세에도 상승하면 매도 압력 실패로 표시한다. 전체 CVD·세력 흡수·미래 반전 확정은 아니다.
- **원본 체결 정합성:** Bithumb 실제 REST에서 다른 체결행이 같은 sequential_id를 공유하는 사례를 확인했다. 별개 관측 행을 보존하고 같은 밀리초를 묶어 순서를 발명하지 않는다. 고유 체결수는 미확인이라고 표시한다. Bitget의 충돌 ID는 계속 거부한다.
- **발송 직전 무효화:** 기존 선물 방향 증거가 발송 시점의 현재 호가에서 이미 반대로 무너졌는지 재검사한다. 기존 증거·종목 안전차단을 제거하지 않았다.
- **발송 영수증 강화:** 메시지 본문, 기록된 전송시각, 응답수신시각, Bot API 시각, 기준가격, 현재 호가와 압력-반응 근거를 비공개KV에 보존한다. 공개 건강상태에서는 상세본문·근거를 제외한다.
- **연결 보존:** 기존5분Cron, AI/KV/Telegram/GitHub 바인딩, GPT 기존 감시, 발송 상한 유지. 계좌·실제 주문·인위적 테스트 Telegram 없음.

## 3. 실제 운영 중 발견한 문제와 최종 수리
V27/V27.1은 테스트와 코드배포를 통과했지만 실제 자연Cron에서 새 Bitget 자료를 읽지 못한 회차가 있었다. 12:00KST 자연실행이12:02:20까지11:55:58 자료를 읽었고, 새 자료는12:01:01 GitHub main에 저장돼 있었다. 45초 대기를90초로 늘린 수정만으로 해결됐다고 판정하지 않았다.

실제 Cloudflare에서 기존 GITHUB_DISPATCH_TOKEN의 Contents 읽기를 확인한 뒤, V27.2는 인증된 최신파일 조회를 우선 사용한다. 토큰은 api.github.com에만 전달하고 public raw fallback 및 오류 진단에 노출하지 않는다. 기존90초 데이터 신선도·동일 수집회차·원본 시각 연결 기준은 그대로 유지한다.
