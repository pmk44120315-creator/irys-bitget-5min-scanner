## 6. 실패·한계도 보존
- 초기 자동push는 workflow 권한 문제로 실패했다. 완료로 보고하지 않았다.
- 역사분석 첫 실행은 원격 파일의 주석3줄 차이로 hash검사에서 중단됐다. 실제 ZIP 원본을 받아 AST와 바이트차이를 검토한 후 검증한 원격 소스hash로 고정했다.
- 역사연구 run42545691996의 원본 복원/비교는 성공했으나 후속 별도 HTTP상태조회 단계는 실패했다. 전체 run을PASS로 표현하지 않는다. 운영 확인은 별도 성공 run으로 수행했다.
- 종목을 회차별로 관찰하는 구조라 관측 공백이 있고 미래 호가 결과가 빠지는 경우가 남는다.24시간무공백·모든목표시점완전측정을 보장하지 않는다.
- 개선된 실전 방향모델, 적중률 향상, 실제 거래수익은 아직 입증되지 않았다. 이번에 실제 반영한 것은 수집기 복구·관측기간 오류 수정·수급과 실제 미래호가의 자동 비교다.
