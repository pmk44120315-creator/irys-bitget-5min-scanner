# IRYS V26 — 실제 체결 기반 방향 판단 연구 엔진 / 개발·검증 인계

기록일: 2026-11-01 KST

## 1. 목표 및 경계
- 목표: Bitget 선물 LONG/SHORT + Bithumb 현물 BUY 초기 흐름을 **객관적인 사후 성과**로 비교해 방향 판단의 정확성과 경제성을 개선한다.
- 과도한 1분봉 연속 조건/무의미한 고정 거래대금 차단을 새로 만들지 않는다.
- V24 운영 Cloudflare `irys-surge-monitor`, Cron `*/5 * * * *`, KV, Workers AI, Telegram 바인딩, 기존 GPT 매시간 감시와 운영 알림 방식은 이번 수정에서 변경하지 않는다.
- **V26은 독립 prospective shadow 연구**이며 매수/롱/숏 진입 신호가 아니다. 자동주문/텔레그램 발송 없음. 실제 예측 정확도 향상 및 경제적 수익성 입증 전까지 승격 불가.
- 이전 V25 알림 편중 개선은 `fix/irys-v25-balanced-bitget-watch-research-20261101` 브랜치의 테스트 전용 변경으로 보관. Cloudflare 배포하지 않음.

## 2. 확인된 기존 문제
- 정상 비트겟 암호화폐 선물 465개를 인식한 실행에서도, 정밀한 15분 실제 체결을 대조하는 기존 V18 수집기는 매 스캔 최대 6개 시장을 대상으로 한다. 이는 근거 공백이지 임의로 '수급 없음'을 의미하지 않는다.
- V21, V22의 사후 매도/매수 방향 연구에서 수익성이 입증되지 않았다. 기존 V22 데이터는 가격만 있는 이벤트와 실제 시간 일치 정밀 수급 검증 이벤트를 구별한다.
- 기존 연구의 확정 이익 및 사용자의 실제 계좌 거래 수익은 전혀 입증되지 않았다.

## 3. 새 기능(실제 코드)
- `v26_direction_core.py`: 발행 당시 V22 동결 피처만 사용해 사전에 정의한 8가지 방향 가설을 함께 기록한다. `REAL_TAKER_PRICE_ALIGNED`, `PRICE_TAKER_DISAGREEMENT_UNRESOLVED`, `PRICE_ONLY` 등을 나눈다.
- 매도 체결이 많아도 가격이 오르는 상황을 단순 SHORT로 확정하지 않고, 흡수/소진 가능성을 확인되지 않은 별도 가설로 둔다. 두 번의 오더북 스냅샷은 지속 흡수 증거가 아니며 OI 변동은 포지션 보유자의 롱/숏 방향을 증명하지 않는다.
- `v26_direction_runtime.py`: 발행 후 최대 4분 이내의 신규 V22 원본 이벤트 중 **미래 결과가 아직 없는 이벤트만** 등록하고 방향을 불변 저장한다.
- 5분/15분 이후 기존 V22가 실제 공개 bid/ask 시각과 함께 기록한 결과만 수집한다. 시작 시점의 원본 호가가 변조되거나 미래 시각이 맞지 않으면 성공을 인정하지 않는다.
- `data/v26_direction_latest.json`, `data/v26_direction_state.json` 에만 독립 저장한다. 실제 실행 가능한 계좌 손익이 아니라 공개 호가 교차 + 가정 비용 0.2% 결과라고 분명히 표시한다.
- `.github/workflows/v26-forward-shadow.yml`: 성공한 기존 V18/V21/V22 연구 실행을 받은 이후에만 독립 연구 작업을 수행한다. 원본 스캐너와 Cloudflare·Telegram 코드는 수정하지 않는다. 트리거가 실제 운영에서 실행되었는지와 두 차례 이상의 결과 업데이트는 별도로 확인한다.
