# IRYS V21 — 조건식 방향 추측을 학습형 미래 예측으로 교체

## 목표와 완료 범위
이 버전은 알림을 무조건 늘리거나 영구 차단하는 대신, 가격·수급 관측을 실제 이후 가격과 학습하고 별도 미래 호가로 평가한다. 현재 소스·테스트·학습 보고서를 보존하는 문서이며, 운영 반영과 Cloudflare 배포 성공은 별도 실제 로그로 확인해야 한다.

## 기존 문제
V20은 V19/AI 실험 알림을 false로 막았지만 방향 정확도를 해결하지 못했다. 최근 5분 가격·체결이 같은 방향이라는 사실과 미래 5분 방향을 맞히는 능력은 다르다. 기존 V20 모델은 가격·체결 불일치 사례를 연구 대상에서도 제외했다. 따라서 단순히 신호 차단 조건을 완화하거나 모든 신호를 반대로 보내는 방법은 채택하지 않았다.

## 실제 구현
- 빗썸/비트겟 및 5분/15분을 분리한 지도학습 분류기. 정규화 로지스틱 회귀와 깊이를 제한한 랜덤포레스트를 사전에 정한 작은 실험군으로 비교.
- 실제 가격 구조·가속도·시장 대비 움직임·순체결·체결 변화·가격과 체결의 불일치·호가 표본·OI·펀딩·자료 누락을 특징으로 사용. 누락된 체결은 0인 실체결로 조작하지 않음.
- 가격·체결 불일치를 일괄 탈락시키지 않음. 20개 연속 1분봉, 일정 거래대금, OI 부호, 첫 눌림은 새 모델의 필수 조건이 아님.
- 시간순 학습/모델선택/최종 시험을 분리. 해당 시각에 아직 공개되지 않은 정답은 학습에서 제외. 시간 경계에는 예측기간+10분 간격을 두고, 같은 종목의 겹치는 예측을 제거.
- 이미 공개된 과거 시험 결과로 새로운 모델을 다시 고르지 않고 모델 가중치와 SHA를 고정. 이후 별도 실제 호가 결과로 검증.
- 실시간 계산은 외부 LLM/API 키/Cloudflare AI 사용량 없이 Python 표준 라이브러리로 실행. 학습 단계만 고정 scikit-learn 1.7.2 사용.
- 기존 V18 자동 실행에 추가되며 원래 시장 수집과 데이터는 유지. 별도 Cron을 늘리지 않음.

### 해석상 제한
- 최종 39건은 6개 시간대에 몰렸고 전체 비트겟 자료 기간도 약24.7시간이다. 독립 미래 성능을 보장하기에 충분하지 않다.
- 위 수익률은 공식 완료 가격 대용치이며 실제 주문 체결 결과가 아니다. 0.10/0.20/0.40% 비용은 시나리오이지 사용자 계좌 수수료가 아니다.
- 빗썸 원래 후보가 이미 오른 종목에 치우쳐 있다. 아직 전 시장 상승 직전 탐지력을 입증한 모델이 아니다.
- 서로 다른 수의 표본을 선택한 모델과 전체 시장 기준선을 단순 비교하여 동일 조건 성능 개선이라고 표현하지 않는다.
- 연구 점수는 보정된 실전 승률이 아니며 알림에 확률로 표시하지 않는다.

## 영구 OFF 대신 실제 성과에 따른 전송 자격
고정된 모델로 예측을 만든 다음 실제 최우선 매수·매도호가를 기록한다. 롱은 매도호가 진입/매수호가 종료, 숏은 반대로 비교한다. 이 역시 실제 체결은 아니므로 비용 가정을 추가한다.
종목·매수/매도 방향·예측기간·모델을 구분해 결과를 평가하고, 시간대 묶음 단위 불확실성 하한과 최근 결과가 양수인지 확인한다. 미래 결과가 누락된 사례도 기록하여 결과가 좋은 사례만 남는 편향을 방지한다.
최소 독립 시간 범위/시간대 수 및 자료 수집률은 통계 검증용 기준이며 가격/거래량 진입 조건이 아니다. 기준 충족만으로 미래 수익이 보장되는 것은 아니다.

새 전송기는 자격 없는 후보를 보내지 않지만 false 고정 스위치로 영구 차단하지 않는다. 실제 미래 근거를 충족한 모델은 신선한 자료와 현재 호가, 유효 종료시각, 추격으로 소진된 보수적 기대이익을 확인한 뒤 전송 대상이 된다. 같은 모델·종목·방향은1시간 반복 억제, 신규 경로 전체2건/시간 제한은 스팸 방지용이다.
V19의 실패한 반응형 방향 알림과 근거 없는 LLM 방향 발송은 다시 켜지 않는다. 기존 보호된 신호와 ChatGPT 매시간 감시는 유지한다.

## 재현된 결함과 수정
- 요청 전에 찍은 시각으로 최신 호가를 검사하여 네트워크 중 생성된 정상 호가를 미래로 오인: 응답 시각 기준 검증으로 수정.
- 모델 파일이 비어도 ACTIVE로 보일 수 있음: 무결성 실패로 표시.
- 정답 가격 누락을 분모에서 숨김: 별도 누락 장부와 자격 계산에 포함.
- 정기 실행이 목표 시각 직전에 오면 5분 정답을 놓침: 기존 실행 내에서 임박한 실제 목표 시각에 맞춰 호가 표본화. 먼 미래 목표로 현재 실행을 멈추지 않음.
- 전송기가 새 예측 파일 게시 직전에 읽으면 다음5분에 이미 오래됨: 이미 검증 자격이 있는 모델에 한해 짧은 재조회로 새 게시를 확인. 후보·근거가 없는 상황은 기존 감시를 지연하지 않음.
