## 아직 확정할 수 없는 내용
- 사용자 **휴대전화에 실제로 받은 정확한 메시지 개수**, 개인별 읽음 확인은 접근 불가.
- Cloudflare KV 원본 영수증 열람은 기존 scoped Cloudflare token 권한 부족으로 HTTP 401; Workers Observability 과거 조회도 HTTP 400, 따라서 **각 V19 실송 메시지별 실제 방향 적중률은 미확인**.
- V20 독립 자연 Cron 이후 정상 지속 운용 및 새 연구 신호의 독립 기간 성공률은 추가 실제 증거로 검증해야 함. 연구 기록만으로 실전 알림 재가동 금지.

## 정리
방향성 예측 정확도가 입증되지 않은 모델을 반복 발송하도록 만든 결함을 제거하고, 기존 감시/시장 증거 수집 및 독립적인 실제 미래 성과 측정을 유지한다. 더 나은 예측력이 입증되면 계측된 근거와 안전한 테스트 후 별도로 운영 승격을 판단한다.
