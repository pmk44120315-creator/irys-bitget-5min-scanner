# IRYS V18 — 실제 예측엔진 개발/검증 결과 및 운영 판단
기준: 2026-10-30 / 연구 브랜치: `research/irys-v18-walkforward-forecast-20261030`

## 목적
기존 V17처럼 알림을 사후 차단하는 데서 끝내지 않고 미래 5/15분 방향을 학습·평가하는 실제 코드 구현. 빗썸 현물 BUY와 비트겟 선물 LONG/SHORT는 독립된 모델·데이터로 취급한다.

## 확인된 구조적 원인
기존 비트겟 수급 실증 수집의 후보 선택은 다음을 HARD로 요구함:
- `abs(p5)>=0.1`, `abs(p15)>=0.15`, `p5*p15>0`, `q15>=15,000`.
- 따라서 **5분과 15분 가격 방향이 반대인 초기 반전 후보가 실제 15분 체결 수집 전에 탈락**.
- 비트겟의 실증 `futures_flow`는 전체 시장이 아니라 일부 선정 종목. 이를 전체 코인의 검증된 CVD처럼 취급하면 안 됨.
- Cloudflare Workers AI 언어모델 응답은 실제 미래 가격 통계 학습·보정의 대용품이 아님.

## 실제 작성한 코드
1. `research/v18_prediction_engine.mjs`: 비트겟 29개 관측 특징. 가격 구조, 시간별 추세/가속, 거래대금, OI, 펀딩, 최신 5분 실제 체결 흐름, 책 호가 참고/결측 표시. **미래 가격은 입력하지 않음**.
2. `research/v18_spot_prediction_engine.mjs`: 빗썸 독립 10개 특징. 선물 학습 가중치 재사용 금지.
3. `research/v18_walkforward_train.mjs`: 과거 자료만 학습, 60분 embargo, 검증 시간 분리, 실제 이후 가격과 비교, 미래 데이터 누수 금지, 실행 비용은 별도 가정으로 표시. 학습 모델 자동 배포 안 함.
4. `research/v18_online_adaptive_replay.mjs`: 정답 가격이 **실제로 나중에 게시된 시각** 이후에만 전문가 가중치를 조절하는 연구용 온라인 적응 엔진. 비트겟·빗썸 개별 평가, 빗썸의 숏 평가를 BUY 실적에 포함 금지.
5. `research/v18_flow_selector.py`: 초기 반전·수급 변화 종목도 실제 수급 데이터 수집 대상으로 선정하고 종목 신원·시계열 무결성 유지. **15분/5분 같은 방향 강제 HARD 삭제**. 기존 검증된 실제 호가 2회 연결은 우선 처리.
6. `bitget_futures_cvd.py` (연구 브랜치에만): `v18_select=False` 기본값. 선택 시에만 실제 Bitget 15분 체결·호가를 V18 후보에서 수집. **기본 운영 경로는 수정 없이 보존**.

## 실증
- 과거 GitHub `main` 시장 스냅샷 866개 독립 재생.
- 비트겟 15분 미래 가격 매칭 관측 약 5.5천 건. 미래 가격 완결 기록은 약 16시간 분량이라 여러 시장일·레짐을 검증하기에 부족.
- 비트겟 **최초 방향 분류형 학습 모델**의 사후 시간분리 시험: 선택 361건, 보합 제외 방향 40.4% 적중. 기대 성능 미달.
- 비트겟 **온라인 지연보상 적응 모델**: 높은 합의 선택 1,971건, 보합 제외 방향 45.1% 적중. 실전 배포 부적합.
- 빗썸 온라인 모델의 **현물 BUY에 해당하는 롱 선택만** 평가: 331건, 보합 제외 50.6% 적중. 평균 기대 비용 차감 후 수익성 근거 없음. 빗썸 숏 판단의 겉보기 적중률은 현물 BUY 성과가 아님.
- V17 선택과 비교: 신규 후보 수집 선택 5,190건, 그중 기존에 사전 제외되던 반전 후보 포함 2,646건. 이는 **방향적중 개선이 아니라 실제 수급 계측 후보 범위 개선**만 입증. V18로 무작정 교체하면 기존 V17이 수집하던 일부 유효 종목을 잃을 수 있어 동시 실증 필요.
